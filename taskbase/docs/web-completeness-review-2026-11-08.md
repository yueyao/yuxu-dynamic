# Web 端功能完整性复核

日期：2026-11-08
范围：登录、总览、节目库、候选节目、单集、转写、采集任务、调度、应用、任务、对外 API
方法：代码/接口对照、实际点击、页面截图、真实任务验证

## 结论

Web 端主链路已经完整：

```text
登录 → 节目库/候选 → 采集单集 → 选单集/只看今年 → 转写队列
→ Worker 执行 → 服务端入库 → 阅读/Markdown 下载 → 对外 API
```

但按“后台管理系统”的标准，部分能力还是**够用但不完整**，主要是：

1. 节目/单集/任务/转写稿缺少真正分页
2. 节目缺少编辑、删除、暂停更新
3. Worker 缺少在线状态和心跳
4. 调度缺少编辑和未来触发预览

## 本轮复核发现并修复

| 问题 | 处理 |
| --- | --- |
| 已取消的队列项不可见，无法重试 | 状态筛选增加「已取消」，可批量重试 |
| 总览把候选节目算进节目库 | 分开显示节目库/候选数量，快照只取已采集 |
| 采集弹窗可能沿用节目库旧选择 | 新建采集默认全部未忽略节目 |
| 默认采集包含已忽略节目 | 后端默认排除 archived |
| 首次采集失败被当成已采集 | 以“有单集或成功/部分成功”判断已采集 |
| 转写队列挤占历史 | Tab + 分页 + 筛选 |
| 取消待转写无效 | 修复 markCanceled 未部署 |

## 验收结论

- 核心业务闭环：通过
- 日常运营：基本通过
- 大规模管理（100+ 节目、1000+ 单集）：需要先补分页和节目生命周期
- 可对外交付：转写稿 API 已具备，但应补 HTTPS
