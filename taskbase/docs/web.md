# Yuxun Web 使用文档

更新：2026-11-08
适用：远端 Taskbase Web 服务

## 1. 入口与登录

```text
http://43.156.253.152/
```

- 用户名：`owner`
- 密码：本机 `taskbase/.deploy/tencent-owner-password`
- 登录状态保存在服务端数据库中，默认保持 30 天；重启 Web 服务也不会退出

查看密码：

```sh
cat taskbase/.deploy/tencent-owner-password
```

当前入口是 HTTP，不是 HTTPS；不要在不信任的网络中登录。

## 2. 页面结构

| 页面 | 用途 |
| --- | --- |
| 总览 | 任务、节目、单集、最近采集 |
| 应用 | App、任务定义、Worker Token |
| 调度 | cron 调度与运行历史 |
| 内容库 | 两个 Tab：订阅列表、候选节目 |
| 单集库 | 两个 Tab：单集库、转写列表 |
| 任务 | 播客任务下，两个 Tab：转写任务（默认）、采集任务 |
| 转写稿 | 在 Web 中阅读 Markdown |

旧路由：

- `#/podcast-candidates` → `#/podcast-shows?tab=candidate`
- `#/transcribe-queue` → `#/tasks?tab=transcribe`
- `#/podcast-tasks` → `#/tasks?tab=collect`

## 3. 添加播客

进入「内容库」→「订阅列表」→「添加节目」。

支持：

- 节目页 URL
- RSS URL（有 RSS 时优先全量入库）
- 只填节目页时回退公开页，通常只有 15 集并标记 `partial`

### 内容库：订阅列表与候选节目

「内容库」是一个页面，内部两个 Tab：

- **订阅列表**：至少成功采集过一次的节目，代表会持续更新
- **候选节目**：从榜单导入、还没有成功采集过的节目
- 点击订阅列表中的节目行，可以查看该节目下已抓取的全部单集
- 候选节目首次采集成功后，会自动从候选 Tab 消失并进入订阅列表
- 候选节目可以「忽略」；忽略后不再参与批量采集
- 候选 Tab 可以「显示已忽略」，随时恢复
- 两个 Tab 各自保留搜索、全选和批量采集

添加后可以：

- **同步 / 首次采集**：采集当前节目
- **采集一年 / 采集全部候选**：按最近一年范围批量采集
- **单集**：点开节目，查看全部已抓取单集并勾选转写
- **调度**：为该节目设置 cron
- **记录**：查看采集历史

已知 RSS 见 [RSS 来源](rss-sources.md)。

## 4. 单集库

导航「单集库」页面有两个 Tab：

```text
[单集库] [转写列表]
```

「单集库」展示所有已采集单集，默认：

```text
发布时间 DESC
50 条/页
```

列表字段：

- 发布时间
- 播客
- 单集标题
- 时长
- 采集状态：`采集成功` + 采集时间
- 转写状态：`转写成功` + 转写时间，或「未转写」
- 操作：查看、加入转写、查看转写稿

筛选：

- 搜索播客名、单集标题、episode id
- 按播客
- 发布时间范围
- 转写状态
- 来源
- 排序：发布时间 / 入库时间 / 播客名

说明：

- 搜索播客名会返回该播客下所有单集
- 采集任务不与单集库关联；需要核对某次采集时自行按节目和时间筛选

## 5. 转写

### 提交

1. 打开「内容库」→「订阅列表」
2. 点击节目的「单集」
3. 找到目标单集
4. 点击「转写」

任务会提交到远端 Platform，由 Mac 上的 Yuxun Worker 领取执行。

### 转写队列（选择与顺序）

批量转写不在 CLI 里做选择，统一在 Web 完成：

1. 打开「内容库」→ 某个节目的「单集」
2. 需要时勾选「只看今年」，列表只保留今年的单集
3. 勾选要转写的单集，或点「全选当前显示」
4. 点「加入转写队列」
4. 进入「任务」→「转写任务」

在队列页面可以：

- 用「上移 / 下移」调整执行顺序
- 取消勾选「启用」，暂时跳过某一集
- 点「开始队列」按顺序执行；点「暂停队列」停止继续提交
- 失败的条目可以「重试」
- 运行中的条目不能删除
- 「清空已结束」清理完成/失败项
- 状态筛选包含「已取消」，取消后可批量重试

执行规则：

- Web 负责选择与顺序，Mac Worker 只接收平台下发的任务，不做选择
- 队列一次只提交一集，上一集结束后才提交下一集
- 点过「开始队列」后，Web 重启会自动恢复；「暂停队列」后不会
- Web 重启时会自动对账正在执行的平台任务：成功则补写转写稿并标记完成
- Worker 10 分钟内没有领取任务，队列会自动暂停并提示

### 队列管理

「任务」→「转写任务」只负责队列：

- **转写队列**：待转写、运行中、失败
- 已完成的转写内容在「单集库」→「转写列表」

队列支持：

- 按播客、状态筛选
- 按播客名或单集标题搜索
- 分页，每页 20 项
- 表头全选当前筛选结果
- 多选后批量启用、停用、取消转写、移除、重试
- 每行显示所属播客、单集、状态、任务号
- 单行置顶 / 上移 / 下移
- 运行中的单集可以直接取消（关闭平台任务）

筛选状态会显示在筛选栏右侧；「重置筛选」恢复全部。

### 转写列表

「单集库」→「转写列表」展示已完成转写的内容：

- 所有 Web 转写入口（单集「转写」和「转写队列」）都走服务端队列
- 已有转写稿的单集再次加入队列会被跳过，避免重复转写
- 队列完成的单集自动写入服务端数据库，完成后立刻出现在这里
- 每行显示单集、节目、时长、片段数、引擎、完成时间
- 支持按单集标题或 episode id 搜索
- 可以切换最近 20 / 50 / 100 条
- 每行可以「查看」或直接「下载 MD」
- 阅读页右上角也可以「下载 Markdown」

### 阅读转写稿

完整任务流程见 [转写全流程图](diagrams/transcription-flow.png)。

转写完成后，在单集里点击「转写稿」，会进入：

```text
/#/transcript/<episode-id>
```

这是**阅读页面**，不是下载页面：

- Markdown 标题、列表、段落、时间戳会直接渲染
- 页面显示语言、Provider、模型、时长、片段数
- 可以「复制原文」
- 可以「下载 Markdown」保存 `.md` 文件
- 外部系统可以通过 [转写稿对外 API](api.md) 读取

转写稿页面需要登录 Web；直接打开 URL 时会先走登录。

### 任务状态

在「任务」→「采集任务」中可以看到：

- 排队
- 执行中
- 成功
- 失败/关闭
- 事件、日志和输出

如果一直 `queued`，通常是 Mac Worker 没有运行。

## 6. 调度

每个节目可以有一个 `show/sync` schedule。

当前 9 个 schedule 默认全部停用。

在「调度」页面可以：

- 启用/停用
- 修改 cron
- 查看下次触发
- 查看运行历史
- `run-now` 手动触发一次
- 删除

规则：

- 同一 schedule 有未结束任务时跳过
- 平台停机期间错过的触发不补跑
- 需要补数据时用 `run-now` 或手动同步

## 7. 应用与 Worker Token

「应用」页面可以查看：

- 已注册 App
- 任务定义
- 输入/输出 schema
- Worker Token

Token：

- 只显示一次
- 丢失后可以轮换
- Podcast Worker 和 Transcription Worker 各自独立
- Token 不能用于用户 API

## 8. 常见问题

### 登录失败

- 用户名必须是 `owner`
- 密码读 `taskbase/.deploy/tencent-owner-password`
- 连续失败会短时限流

### 页面打不开

- 确认 `http://43.156.253.152/` 可访问
- 不要用 `:3410`，该端口未在 Lighthouse 防火墙放行
- 服务器上检查 `systemctl status taskbase-web nginx`

### 提交转写后一直排队

在 Mac 上：

```sh
yuxun worker status
yuxun worker logs
```

确认 Worker 运行、Token 正确、`whisper`/`ffmpeg` 可用。

### 没有转写稿

单集还没有执行过转写，或任务失败。先看「任务」中的错误和日志。

### 转写稿显示为空

检查任务是否成功、产物是否上传；当前页面读取平台任务输出或本地转写表。
