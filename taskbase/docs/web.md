# Yuxun Web 使用文档

更新：2026-11-09
适用：远端 Taskbase Web 服务

当前行为与已确认范围以[项目规范与验收审查](../../spec/taskbase-current-spec.md)为索引；生产运维验收暂缓，本文中的服务器地址和凭据路径保留为部署记录。

## 1. 入口与登录

```text
http://43.156.253.152/
```

- 部署记录中的用户名：`owner`；自建环境以初始化配置为准
- 密码：本机 `taskbase/.deploy/tencent-owner-password`
- 登录状态保存在服务端数据库中，默认保持 30 天；重启 Web 服务也不会退出

查看密码：

```sh
cat taskbase/.deploy/tencent-owner-password
```

上述地址是历史 HTTP 入口；仓库已提供 [HTTPS 配置与切换步骤](https.md)，本次修复未更新线上入口。

## 2. 页面结构

| 页面 | 用途 |
| --- | --- |
| 总览 | 任务、节目、单集、最近采集 |
| 应用 | App、任务定义、Worker Token |
| 调度 | cron 调度与运行历史 |
| 内容库 | 两个 Tab：订阅列表、候选节目 |
| 单集库 | 两个 Tab：单集库、转写列表 |
| 任务 | 播客任务下，两个 Tab：转写任务（默认）、采集任务 |
| 转写稿 | 在 Web 中阅读 Markdown |

旧路由：

- `#/podcast-candidates` → `#/podcast-shows?tab=candidate`
- `#/transcribe-queue` → `#/tasks?tab=transcribe`
- `#/podcast-tasks` → `#/tasks?tab=collect`

## 3. 添加播客

进入「内容库」→「订阅列表」→「添加节目」。

支持：

- 节目页 URL
- RSS URL（读取 Feed 后按日期范围入库；默认最近一年）
- 只填节目页时回退公开页，通常只有 15 集并标记 `partial`

已登记 RSS 但抓取失败时会记录失败，不自动回退页面。RSS 的 `full` 是来源覆盖标记，不表示所有历史均已保存。需要更早的数据时应明确扩大采集日期范围，且 Feed 本身可能不含完整历史。

### 内容库：订阅列表与候选节目

「内容库」是一个页面，内部两个 Tab：

- **订阅列表**：已有单集或成功/partial 采集记录的节目；持续更新还需另行配置并启用调度
- **候选节目**：从榜单导入、还没有成功采集过的节目
- 点击订阅列表中的节目行，可以查看该节目下已抓取的全部单集
- 「已转写」列显示该节目下已有转写稿的单集数（按单集去重），例如 `已转写 12 集 / 共 95 集`；候选节目为 `—`
- 候选节目首次采集成功后，会自动从候选 Tab 消失并进入订阅列表
- 候选节目可以「忽略」；忽略后不再参与批量采集
- 候选 Tab 可以「显示已忽略」，随时恢复
- 两个 Tab 各自保留搜索、全选和批量采集
- 节目列表按 20 项分页，搜索按回车在服务端查询；全选选择当前页，可跨页累计选择
- 「采集一年 / 采集全部候选」处理整个对应范围，不受当前页限制
- 节目单集弹窗按 50 集分页，可查看超过 500 集的节目

添加后可以：

- **同步 / 首次采集**：采集当前节目
- **采集一年 / 采集全部候选**：按最近一年范围批量采集
- **单集**：点开节目，查看全部已抓取单集并勾选转写
- **调度**：为该节目设置 cron
- **记录**：查看采集历史

已知 RSS 见 [RSS 来源](rss-sources.md)。

## 4. 单集库

导航「单集库」页面有两个 Tab：

```text
[单集库] [转写列表]
```

「单集库」展示所有已采集单集，默认：

```text
发布时间 DESC
50 条/页
```

列表字段：

- 发布时间
- 播客
- 单集标题
- 时长
- 采集状态：`采集成功` + 采集时间
- 转写状态：`转写成功` + 转写时间，或「未转写」
- 操作：查看、加入转写、查看转写稿

筛选：

- 搜索播客名、单集标题、episode id
- 按播客
- 发布时间范围
- 转写状态
- 来源
- 排序：发布时间 / 入库时间 / 播客名

说明：

- 搜索播客名会返回该播客下所有单集
- 转写队列运行中时，单集库每 15 秒自动刷新状态
- 采集任务不与单集库关联；需要核对某次采集时自行按节目和时间筛选

## 5. 转写

### 提交

1. 打开「内容库」→「订阅列表」
2. 点击节目的「单集」
3. 找到目标单集
4. 点击「转写」

任务会提交到远端 Platform，由 Mac 上的 Yuxun Worker 领取执行。

### 转写队列（选择与顺序）

批量转写不在 CLI 里做选择，统一在 Web 完成：

1. 打开「内容库」→ 某个节目的「单集」
2. 需要时勾选「只看今年」，列表只保留今年的单集
3. 勾选要转写的单集，或点「全选当前显示」
4. 点「加入转写队列」
5. 进入「任务」→「转写任务」

在队列页面可以：

- 用「上移 / 下移」调整执行顺序
- 取消勾选「启用」，暂时跳过某一集
- 点「开始队列」按顺序执行；点「暂停队列」停止继续提交
- 失败的条目可以「重试」
- 运行中的条目不能删除
- 「清空已结束」清理完成/失败项
- 状态筛选包含「已取消」，取消后可批量重试

执行规则：

- Web 负责选择与顺序，Mac Worker 只接收平台下发的任务，不做选择
- 队列一次只提交一集，上一集结束后才提交下一集
- 点过「开始队列」后，Web 重启会自动恢复；「暂停队列」后不会
- Web 重启时会自动对账正在执行的平台任务：成功则补写转写稿并标记完成
- 提交响应丢失时用持久化幂等键找回原任务，避免重复转写；「确认提交中」「正在入库」会显示恢复阶段
- 入库失败保留运行状态并自动重试，稿件保存成功后才计入已完成；取消请求失败会保留任务关联供再次处理
- Worker 10 分钟内没有领取任务，队列会自动暂停并提示

稿件入库以 Web 队列/Runner 为准，这是当前已确认的职责边界。CLI 直接提交的任务沿用现有结果/产物流程，本轮不要求其自动进入 Web 稿件库；任务成功本身不代表已入库。

自动推进依赖 Web 进程持续运行，并设置有效的 `YUXUN_OWNER_USERNAME`（默认 `owner`）和 `YUXUN_OWNER_PASSWORD`；兼容对应 `TASKBASE_*`，新别名优先，显式服务选项优先于环境变量。浏览器登录本身不会替代该服务端配置。暂停队列阻止继续提交，正在运行的单集需单独取消。

### 队列管理

「任务」→「转写任务」只负责队列：

- **转写队列**：待转写、运行中、失败
- 已完成的转写内容在「单集库」→「转写列表」

队列支持：

- 按播客、状态筛选
- 按播客名或单集标题搜索
- 分页，每页 20 项
- 表头全选当前页，可跨页累计选择
- 多选后批量启用、停用、取消转写、移除、重试
- 每行显示所属播客、单集、状态、任务号
- 单行置顶 / 上移 / 下移
- 运行中的单集可以直接取消（关闭平台任务）

筛选状态会显示在筛选栏右侧；「重置筛选」恢复全部。

### 转写列表

「单集库」→「转写列表」展示已完成转写的内容：

- 所有 Web 转写入口（单集「转写」和「转写队列」）都走服务端队列
- 已有转写稿的单集再次加入队列会被跳过，避免重复转写
- 队列完成的单集自动写入服务端数据库，完成后立刻出现在这里
- 每行显示单集、节目、时长、片段数、引擎、完成时间
- 支持按单集标题或 episode id 搜索
- 按每页 20 / 50 / 100 条翻页，搜索总数由服务端计算；列表只返回摘要，详情读取全文
- 每行可以「查看」或直接「下载 MD」
- 阅读页右上角也可以「下载 Markdown」

以上指当前页面按钮。兼容接口 `POST /api/podcast/episodes/:id/transcribe` 和 CLI 仍直接创建平台任务，不保证自动进入该转写列表；它们的成功结果和产物保存在平台任务中。

### 阅读转写稿

当前流程见[架构说明](architecture.md#9-转写流程)；[转写全流程 PNG](diagrams/transcription-flow.png)为历史渲染图，未包含全部队列补偿细节。

转写完成后，在单集里点击「转写稿」，会进入：

```text
/#/transcript/<episode-id>
```

这是**阅读页面**，不是下载页面：

- Markdown 标题、列表、段落、时间戳会直接渲染
- 页面显示语言、Provider、模型、时长、片段数
- 可以「复制原文」
- 可以「下载 Markdown」保存 `.md` 文件
- 外部系统可以通过 [转写稿对外 API](api.md) 读取

转写稿页面需要登录 Web；直接打开 URL 时会先走登录。

### 任务状态

在「任务」→「采集任务」中可以看到：

- 排队
- 执行中
- 成功
- 失败/关闭
- 事件、日志和输出

如果一直 `queued`，通常是 Mac Worker 没有运行。

## 6. 调度

建议每个节目配置一个 `show/sync` schedule；当前接口没有按节目去重，重复创建会形成多个独立调度。

种子脚本创建的 9 个 schedule 默认全部停用，实际部署状态以页面查询为准。

在「调度」页面可以：

- 启用/停用
- 查看下次触发
- 查看运行历史
- `run-now` 手动触发一次
- 删除

修改已有调度的 cron、时区和输入需使用平台 `PATCH /v1/schedules/:id`；当前 Web 没有这些字段的编辑表单。

规则：

- 同一 schedule 有未结束任务时跳过
- 扫描时超过默认 5 分钟宽限窗口的触发会跳过；窗口内仍可能执行
- 需要补数据时用 `run-now` 或手动同步

## 7. 应用与 Worker Token

应用页显示 Worker 是否在最近 90 秒内联系过平台，以及最近联系时间。空闲 Worker 轮询领取任务时也会更新该状态；「在线」表示近期连接正常，不代表 ASR 模型已就绪。

「应用」页面可以查看：

- 已注册 App
- 任务定义
- 输入/输出 schema
- Worker Token

Token：

- 只显示一次
- 丢失后可以轮换
- Podcast Worker 和 Transcription Worker 各自独立
- Token 不能用于用户 API

## 8. 常见问题

### 登录失败

- 历史部署用户名为 `owner`；自建环境检查初始化时的用户名
- 密码读 `taskbase/.deploy/tencent-owner-password`
- 连续失败会短时限流

### 页面打不开

- 确认 `http://43.156.253.152/` 可访问
- 不要用 `:3410`，该端口未在 Lighthouse 防火墙放行
- 服务器上检查 `systemctl status taskbase-web nginx`

### 提交转写后一直排队

在 Mac 上：

```sh
yuxun worker status
yuxun worker logs
```

确认 Worker 运行、Token 正确、`whisper`/`ffmpeg` 可用。

### 没有转写稿

单集还没有执行过转写，或任务失败。先看「任务」中的错误和日志。

### 转写稿显示为空

检查任务是否成功、产物是否上传；当前页面读取平台任务输出或本地转写表。
